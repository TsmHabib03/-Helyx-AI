Streaming

Set "stream": true for Server-Sent Events. Works with the OpenAI SDK's stream=True.

from openai import OpenAI

client = OpenAI(
    base_url="https://helyxai.space/v1",
    api_key="helyx_sk_YourApiKeyHere",
)

stream = client.chat.completions.create(
    model="claude-sonnet-4",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True,
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

Retries & Overload

On 503 Overloaded, wait and retry with exponential backoff. We recommend up to 3 retries. 

import time, openai

client = openai.OpenAI(
    base_url="https://helyxai.space/v1",
    api_key="helyx_sk_YourApiKeyHere",
)

for attempt in range(3):
    try:
        resp = client.chat.completions.create(
            model="claude-opus-5",
            messages=[{"role": "user", "content": "Hello"}],
        )
        break
    except openai.APIStatusError as e:
        if e.status_code == 503:
            time.sleep(2 ** attempt)
        else:
            raise

SDK Examples

Use the official OpenAI SDKs — just swap the base URL and API key.

Python

from openai import OpenAI

client = OpenAI(
    base_url="https://helyxai.space/v1",
    api_key="helyx_sk_YourApiKeyHere",
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain quantum computing in one paragraph."}
    ]
)

print(response.choices[0].message.content)

Node.js

const client = new OpenAI({
  baseURL: "https://helyxai.space/v1",

});

    { role: "system", content: "You are a helpful assistant." },

  ]
});

console.log(response.choices[0].message.content);
